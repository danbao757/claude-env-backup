# 去AI味改稿

用户给你一段已经存在的文本，你要交回一段洗掉AI味的版本。改的是味，不是意。

## 先定两件事

**文本类型决定力度。** 开工前先判断这段文字是什么，不同类型的"正常"长得不一样：

- 正式文档（报告、技术文档、需求说明）：标题、编号、列表这些结构骨架是正常的，留着。要洗的是句式、黑话、空洞的总结和升华。
- 社交与自媒体（小红书、公众号、朋友圈、帖子）：可以更口语，句子长短错落，删掉排版表演（emoji 小标题、满屏加粗、排比三连）。
- 消息与邮件（发给同事、客户、领导）：保持简短，重点去客服腔和客套堆叠，别把一条消息改成文章。
- 分不清就按原文的正式程度来，宁可改轻不可改重。

**允许润色，但只润AI的部分和明显不通顺的部分。** 事实、数字、专名、代码、链接一个不动；观点和立场可以换说法，不能换态度；原文的格式骨架（是不是 markdown、有没有小节）保持原样，除非用户要求重排。

## 什么不能做

- 不加戏。不添加原文没有的观点、例子、比喻、情绪。加东西换来的"人味"是假人味。
- 不越改越长。润色允许变短（删废话），不应该明显变长。
- 不把作者自己的话磨光。原文里那些粗糙但具体的表达——口语、个人用词习惯、稍微绕一点的句子——往往是最有人味的部分。润的是AI的部分，人的部分别碰。
- 文本本来就没多少AI味时，直说"没发现明显AI味，只有X处小问题"，别为改而改。

## AI味清单

下面是常见的味源，按命中多寡决定重点。每一项都给了改法示例。注意清单是猎场不是法典——正式文档里出现冒号很正常，别机械全灭，逐处判断。

### 句式

**翻案句**：不是……而是……／并非……而是……／与其说……不如说……／表面上看是A，实际上是B。
AI味来自句式在表演深刻，把对比本身当洞察。改法是直接说事实。

> AI：效率提升不是终点，而是新的起点。
> 人：效率提上来了，接下来能干点以前干不了的事。

**顿悟路标**：值得注意的是／更有意思的是／耐人寻味的是／某种意义上说／这里的关键在于／说白了／说穿了。
这些词在替读者惊讶。删掉路标，直接说事，真值得注意的内容自己会立住。

**总分口号**：总而言之／综上所述／由此可见／归根结底／一言以蔽之。短文里出现尤其假。整段总结如果只是重复前文，直接删。

**排比三连**：三个对仗短语并列（更快的X、更强的Y、更好的Z）。留最准的一个，其余删掉或换成具体事实。对仗小标题（"锚定目标，精准发力"）同理，改成老实说事的小标题。

**万能开头**：在当今……快速发展的时代／随着……的不断深入／在数字化浪潮下。开头直接进正题，背景用一句话带过。

**升华结尾**：这不仅是X，更是Y／未来，让我们拭目以待／或许，这正是……的意义所在。写到事情讲完就停，不要替读者总结时代意义。

**工整枚举**：首先／其次／再次／最后用在几百字的短文里。真正的并列关系直接说，或者拆成自然的段落顺序。

### 词汇

- 商业黑话：赋能、抓手、闭环、颗粒度、底层逻辑、顶层设计、组合拳、打法、对齐、拉通、生态、心智、护城河。多数能换成大白话，换不掉的（确属行话且用户圈子在用）可以留。
- 抬价副词：极大地、显著地、充分地、深入地、有效地。删掉，看句子是否损失信息——通常没有。
- 空洞形容：丰富多彩、形式多样、卓有成效、行稳致远、焕然一新。换成具体的事，或者删。
- 翻译腔：进行了讨论（→讨论了）／作出了贡献（→贡献了）／扮演着重要角色（→很关键）／发挥着重要作用（→有用）／对于X而言（→对X来说）。
- AI高频词：堪称、可谓、无疑、毋庸置疑、旨在、致力于、聚焦、深耕、打造、助力、擘画。多数出现在标题和结尾，和升华病一起治。

### 结构

- emoji 或符号装饰的小标题（✨干货分享／▍重点）。emoji 本身在社交文本里不犯法，但标题前的装饰符号是重灾区。
- 满屏加粗。加粗是路标，一条短文里一两处封顶。全是重点等于没有重点。
- 万物皆列表。散文内容硬拆成 bullet 会丢掉句间的因果和转折，能连成段就连成段。
- 每段等长、每句都圆。真人写东西详略不均，重要的多说两句，不重要的带过。

### 语气

- 客服腔：希望这对您有所帮助／如有问题欢迎随时告诉我／很荣幸能……。整句删。
- 教师腔：记住，X是关键／让我们来看看／我们不妨。人称改成"你"或直接省略。
- 过度热情：太棒了！／这是一个非常棒的问题！／感叹号连用。
- 四平八稳没立场：一般来说／通常情况下／在一定程度上，每句都留着退路。原文有判断就把判断亮出来，原文确实没判断就别替它编。
- 太顺滑。每句话都圆、每个观点都接得住，本身也是AI味。真人写作允许一点冗余、让步和先说一半再补。**这条对"允许润色"尤其重要**：不要把每一句都改到完美，改到八成顺就停手，过度打磨会造出另一种机器味。

### 标点

- 破折号——表演停顿（在中文里用——引出金句是最强的AI信号之一）。改成句号断开，或用普通逗号。
- 冒号引出金句（答案只有一个：X）。金句本身多半要重写，冒号随之消失。技术文档里键值、时间、比例前的冒号是正常的，别动。
- 分号串联的工整长句（X；Y；Z）。拆成短句。
- 感叹号连用！！、省略号堆叠。。。。。

## 改写流程

1. 通读全文，找出命中最密集的味源，心里排出前三个。改写围绕重点打，不是逐句过筛子。
2. 对每个AI句，先问"它到底想说什么事实或判断"，再用最普通的话把那个事实说出来。**不要找一个更漂亮的句式去替换旧句式**——把"不是而是"换成"与其说不如说"等于没改。
3. 删优于改。路标词、过渡句、重复的总结段，本来就没信息量，直接删。
4. 改完自查两件事：
   - 信息点：原文每个有效信息在成品里还找得到吗？丢了的要么补回，要么确认它本来就是废话。
   - 顺滑度：通读一遍，如果读起来"太完美"，回头把打磨过头的两三处放回自然状态。
5. 长文本（五百字以上）可以存成文件跑自检脚本：

```
python <本技能目录>/scripts/check_ai_flavor.py <文件路径>
```

脚本报告命中的味源和行号，是复查清单不是硬门槛——每个命中处逐个决定改还是留。短文本直接对照上面的清单目测。

## 交付

只交成品文本。不附改动分析、不附清单命中报告，用户问再给。改动特别大（比如删了整段总结）时，用一句话说明，放在成品后面。

用户后续说"还是有点AI""这句不对"，是正常的迭代，针对指出的问题改，不要全文推倒重来。
